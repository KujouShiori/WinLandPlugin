# FlClash 小岛

作者：Thesed · 版本：1.5.0

在 WinIsland 上查看 FlClash 当前节点、国旗、延迟和实时网速，在岛内切换模式与节点。三个圆角玻璃按钮保留柔光和悬停高光，无呼吸动画。

## 安装与快速开始

1. 安装并启动 [Windows 版 FlClash](https://github.com/chen08209/FlClash/releases)，导入自己的配置，确认可以正常使用。
2. 在 FlClash 的“配置 → 常规”中开启“外部控制”。不同版本可能将此选项放在设置中。仅开放本机控制即可，无需允许局域网访问。
3. 在 WinIsland 插件市场安装“FlClash 小岛”，然后在插件管理中启用。手动安装时，将 `.lwp` 放入 WinIsland 安装目录的 `plugins` 文件夹，退出并重新启动 WinIsland。
4. 打开 WinIsland 设置中的“FlClash 小岛”页面，保持“手动控制地址”为空，点击“保存并测试连接”。出现“已连接 FlClash”即可使用。

首次启用会显示引导提示；设置页提供快速开始和连接诊断。正常安装无需填写地址或密钥，无需管理员权限，也无需安装开发工具。

要求：Windows 11 x64、支持插件 API 2 / 主题 API 2.3.0 的 WinIsland，以及正在运行的 Windows 版 FlClash。旧版 WinIsland 请先更新。

## 小岛操作

- 收起：国旗、最近约一分钟的网速曲线、上传与下载数值。速度按内核累计流量每两秒计算；第一次取样显示 0，下一次取样开始更新。曲线为上传与下载之和。
- 展开：顶部网速曲线及上传、下载数值，下方显示当前节点和三个操作按钮；延迟仅在测速按钮内显示。
- 模式：选择规则、全局或直连。
- 节点：平滑切换到岛内选择器，上行选择策略组，下行选择节点；选中即生效，左侧箭头返回。长名称在列表中换行，悬停可查看完整名称。只显示可手动切换的策略组。
- 测速：只测试当前实际节点，嵌套策略组会解析到当前节点；不会批量测速整组。这里测的是请求延迟，单位 ms，不是下载带宽。显示“—”表示尚无延迟结果。

玻璃底层透出 WinIsland 岛体材质，配色读取 FlClash 主题色并适配岛体明暗。最终透明效果由宿主外观与系统设置决定。

## 自动连接与手动连接

默认读取当前 Windows 用户的 `%APPDATA%\com.follow\clash`，优先读取 FlClash 的 `shared_preferences.json`，其次读取配置文件。

便携版或自定义配置目录：把“FlClash 配置目录”改为包含 `shared_preferences.json` 的文件夹，再测试连接。

自定义控制地址：填写 FlClash 正在使用的本机地址，例如 `http://127.0.0.1:9090`；设置了密钥时填写相同密钥。这里只接受本机地址。清空手动地址即可恢复自动检测。密钥使用密码输入框，不显示在岛上。

## 国旗与网络请求

默认根据节点名称中的国旗或地区名称显示国旗；识别不到时不显示国旗。

可在设置开启“按出口 IP 检测国旗”。开启前会说明：插件通过 FlClash 代理访问 `https://www.cloudflare.com/cdn-cgi/trace`，Cloudflare 会看到出口 IP，插件只保留国家代码，不保存 IP。节点变更或约五分钟后重新检测，失败时退回节点名称识别。规则模式下检测请求可能由规则分流，因此出口国家与节点名称可以不同。

点击测速会让 FlClash 内核使用 `https://www.gstatic.com/generate_204` 测试当前节点。日常状态读取仅访问本机控制接口。插件没有统计上报，不上传订阅、节点配置或控制密钥。

## 常见问题

- 找不到配置：先运行一次 FlClash；检查配置目录，尤其是便携版。
- 连接失败：保持 FlClash 运行并开启外部控制；地址、端口和密钥必须一致。一般可清空手动地址恢复自动检测。
- 未看到小岛：启用插件及“在灵动岛上显示”；其他高优先级内容可能占用小岛，可在展开队列中查看或调整优先级。
- 没有节点选项：配置可能没有可手动切换的 Selector 策略组；自动测速组不能通过此界面手动选节点。
- 没有国旗：节点名无法识别国家；可选择开启出口检测。
- 延迟与 FlClash 显示不同：测量时刻、测试目标或规则不同都会影响结果；本插件只重新测试当前实际节点。

在设置页点击“保存并测试连接”查看提示。日志通常位于 `%LocalAppData%\WinIsland\logs\plugin.flclash-island.log`，分享前请检查其中是否含个人信息。

## 1.4.0：未连接时继续显示网络

FlClash 未运行、控制接口不可用、停止代理连接或选择 DIRECT / 直连模式时，自动显示本机活动物理网卡的上传、下载与曲线。排除回环、隧道及常见虚拟网卡，避免重复统计；这是整台电脑的网卡流量，不限于 FlClash，可能包含局域网传输，不是带宽测速。连接恢复后自动切回 FlClash 内核统计。

未连接时默认直接请求 Cloudflare trace，按公网出口国家显示国旗，跳过系统 HTTP 代理；其他 VPN / TUN 仍可能影响实际出口。仅保留国家代码，不保存公网 IP。可在设置关闭“未连接时检测本机出口国旗”。约五分钟后重新检测，失败约一分钟后重试；没有网络或检测失败时不猜测国家。无默认网关的特殊网络环境可能无法统计。

首次取样显示 0，下一次取样开始更新；网络模式切换可能短暂等待下一次取样。未连接且控制接口不可用时，模式和节点操作不可用，右侧按钮用于重新尝试连接。
