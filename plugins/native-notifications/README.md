# Windows 原生通知

把 Windows 系统通知显示到 WinIsland 灵动岛上。作者：Timi。

## 功能

- **简要条**：新通知先在小岛上显示一行简要条。应用图标和标题固定，正文放不下时从右往左循环滚动。同时到达多条时只显示最新一条，右侧的「+N」是其余条数。
- **通知列表**：所有通知都会进入列表，按应用分组，最新的在上。鼠标移到小岛上展开查看，每条显示标题、时间和最多三行正文；内容多时用鼠标滚轮滚动，底部有「向下滑动查看更多」提示。
- **查看时不打扰**：查看列表时新到的通知插到最上面并标「新」，不会盖住正在看的内容。
- **清除**：点一条会打开对应应用并清除这一条；悬停时出现的 × 清除单条，组标题上的 × 清除该应用的全部通知，「全部清除」清空列表；切换到对应应用时，它的通知也会自动清除。清除时条目向左滑出，列表随后收拢。
- **与系统同步**：清除的通知会同时从 Windows 通知中心删除；在 Windows 里清掉或被应用撤回的通知，也会自动移出列表。只是查看不算已读。

## 设置

在 WinIsland 的「设置 → Windows 原生通知」中可以：开关通知显示；授予或重新检查通知权限；调整简要条的宽度（170–720）和高度（32–80），以及展开卡片的最大宽度（360–720）和最大高度（200–720）；点「预览通知」同时查看简要条和列表的效果。

## 兼容性与限制

- 需要 WinIsland（宿主 SDK 2.4 及以上），在 Windows 11 上测试。
- 官方宿主把普通内容的简要条宽度上限定在 170，宽度拉条超过 170 不起作用。
- 展开卡片的宽度会带动整组展开卡片一起变宽（宿主按最宽的一张对齐）。
- 收起时的未读小提示（应用图标和条数）需要硬件条插件提供“附件位”（进程内约定键 `WinLand.HardwareClock.AccessorySlot`）。市场上的硬件监控插件目前没有这个位置，这时通知只能在悬停展开的列表里查看；小岛上没有其他内容时，提示会直接显示在小岛上。
- 点开通知只能打开对应的应用：Windows 不提供原通知的点击参数，不能保证跳到具体会话。
- 读取通知需要 Windows 的通知访问权限。设置页显示未授权时，点「授予通知权限 / 重新检查」，并在 Windows 设置里允许访问通知。
- 新通知和通知变化的信号来自 Windows 的 WNF 通知状态（未公开接口），不可用时退回系统的推送通知事件日志；不做周期性轮询。

## 隐私与权限

- 不需要管理员权限，不联网，不写文件；只读取应用自己注册的图标用来显示。
- 通知内容只在内存中显示，不写日志、不落盘、不上传；列表也只在内存里，WinIsland 重启后清空。
- 为了“切换到对应应用时自动清除”，插件会监听前台窗口的切换，只用来判断窗口属于哪个应用，不做记录。
- 会删除 Windows 通知中心里你清除的通知。删除前会核对通知 ID 和创建时间，不会删到别的通知。
