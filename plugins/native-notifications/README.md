# Windows 原生通知

把 Windows 系统通知显示到 WinIsland 灵动岛上。作者：Timi。

## 功能

- **简要通知条**：新通知先以一行简要条上岛。应用图标和标题固定，正文放不下时从右往左循环滚动，并至少停留到滚完一遍（最长 20 秒）。
- **展开全文**：鼠标移到小岛上展开完整卡片，显示来源应用、图标、标题和正文。正文长时卡片自动加高（最高 360），再长可用滚轮滚动。展开期间暂停自动收起。
- **打开来源应用**：点击卡片打开发出通知的应用。Windows 不提供原通知的点击参数，所以不能保证跳到具体会话。
- **未读列表**：简要条到时自动收起、期间没展开过的通知记为未读。鼠标移到小岛上可查看未读列表（按应用分组，显示每个应用最近一条消息的全文），可以打开应用、清除某个应用，或“全部清除”。
- **已读同步**：展开过、打开、关闭或清除的通知，会同时从 Windows 通知中心删除。应用自己撤回、或在 Windows 里清掉的通知，也会自动移出未读。
- **可调尺寸**：设置页可以拖动调整简要通知条的宽度和高度，并有“预览”按钮。

## 兼容性与限制

- 需要 WinIsland（宿主 SDK 2.4 及以上）。
- 官方宿主把普通内容的简要条宽度上限定在 170，所以在官方宿主上，宽度拉条超过 170 不起作用。
- 硬件条右侧的未读小提示，需要硬件条插件提供“附件位”（进程内约定键 `WinLand.HardwareClock.AccessorySlot`）。市场上的硬件监控插件目前没有这个位置；这种情况下未读只能在鼠标悬停时的列表里查看。
- 读取通知依赖 Windows 的通知访问权限（UserNotificationListener）。如果设置页显示未授权，请点“授予通知权限 / 重新检查”，并在 Windows 设置里允许访问通知。
- 新通知和通知变化的信号来自 Windows 的 WNF 通知状态（未公开接口），不可用时退回系统的推送通知事件日志；不做周期性轮询。在 Windows 11 上测试。

## 隐私与权限

- 不需要管理员权限，不联网，不读写任何文件。
- 通知正文只在内存中显示，不写日志、不落盘、不上传；未读列表只存在内存里，WinIsland 重启后清空。
- 会删除 Windows 通知中心里你读过或清除的通知（见“已读同步”）。删除前会核对通知 ID 和创建时间，不会删到别的通知。

## 设置

在 WinIsland 的「设置 → Windows 原生通知」中：开关通知显示、授予或重新检查通知权限、调整简要通知条的宽度（170–720）和高度（32–80），以及预览效果。
