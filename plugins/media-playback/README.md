# 媒体播放

作者：Thesed · 版本：1.0.8 · 独立 WinIsland 小部件

在原生媒体卡片的使用习惯上，增加双行歌词、展开后的四排歌词及连续过渡动画。安装后保留原生“正在播放”模块，可自行选择启用哪一个。

## 快速开始

1. 在插件市场安装“媒体播放”，按宿主提示重新加载插件或重启 WinIsland。
2. 打开 WinIsland 设置 → 插件管理，确认“媒体播放”已启用。
3. 在 QQ 音乐等支持 Windows 系统媒体会话的播放器中播放歌曲。没有媒体会话时，小部件不会显示。
4. 鼠标移到小岛上可展开卡片；播放、暂停、上一首、下一首及进度拖动都作用于当前播放器。
5. 若同时出现原生媒体卡和本部件，可关闭原生“正在播放”模块，保留“媒体播放”。

不需要管理员权限，不需要填写账号或接口密钥。测试环境为 Windows 11 x64、WinIsland 1.1.3；需要插件 API 2 和 Core 2.3.0 或更高版本。本包按 win-x64 构建，其他架构尚未验证。

## 相对原生卡片的改动

- 收起状态移除右侧音频条图标，使用两排歌词；第一排为当前内容，第二排预览后续内容。
- 中文每行最多 8 个字，优先按原歌词空格分行；英文按实际文字宽度尽量显示整句，宽度不足才在单词边界换行。
- 展开状态增加细分隔线和右侧四排歌词：上一行、当前行、后续两行。第二排稍大并突出显示。展开排版按实际宽度分行，不使用收起状态的 8 字限制。
- 歌词换句时连续上移、缩放和淡入淡出；展开与收起时，相同文字使用位置和缩放过渡，其余信息渐显。
- 背景沿用原生三层音乐光晕的渐变、位置与频段响应，保留封面、歌曲、歌手、播放器来源及播放控制。
- 增加 QQ 音乐歌词来源，配合网易云和 LRCLIB；处理歌曲名称前缀、多歌手及翻译别名，并按时长排除不匹配的录音版本。
- 各歌词源独立超时，暂时失败自动重试，成功歌词缓存于本地。

## 设置与歌词校准

### 1.0.8：播放状态自动调整优先级

默认启用“播放时优先显示，暂停一分钟后让位”。播放时缩小优先级为 110，连续暂停满 60 秒后降为 0；恢复播放立即提高。没有活动媒体会话时卡片隐藏。其他部件的数值高于闲置值时，就可以优先显示。

设置中可分别修改播放中、闲置和关闭自动调整后的固定优先级，范围 0～999，数值越大越优先，修改立即生效。关闭自动调整后默认固定为 110。恢复播放会重新开始下一次暂停计时；切换页面或重读媒体信息不会重置计时。

请将“设置 → 插件管理 → 媒体播放”的“优先级”留空：宿主中手动填写的固定值会覆盖本插件的动态优先级。支持“展开优先级”的宿主可单独设置展开排列，否则展开排序也可能随优先级改变。其他部件优先级更高、或数值相同时，不保证本部件占据缩小小岛。

WinIsland 设置 → 媒体播放，可开关部件、歌词和音乐光晕，重新检测播放器。

“歌词校准”可在 -10 到 +10 秒间调整：如果歌词落后于声音，向正值调整；如果歌词提前，向负值调整。默认 0 秒。

## 无法显示或同步时

- 没有卡片：先确认播放器正在播放，且能向 Windows 提供系统媒体会话；点击“重新检测播放器”。
- 有封面和歌名但没有歌词：确认歌词开关已开启、网络可用，并等待重试。歌曲名称或歌手不完整、现场版/翻唱版本不同、歌词源缺失，都可能导致匹配失败。
- 歌词有偏移：使用歌词校准。切歌、暂停、继续与拖动进度后会重新按媒体进度定位。
- 所有播放器的兼容性不能保证：小部件使用 Windows 系统媒体接口，没有该接口或没有有效播放进度的软件无法完整同步。QQ 音乐已做实际歌曲检索验证，其他播放器没有逐个实测。
- 没有逐字时间戳的长句，内部换行的播放时机按整句时长估算，不能保证逐字准确。

## 网络、文件与音频

- 歌名、歌手及用于版本匹配的时长会用于 QQ 音乐、网易云和 LRCLIB 公开歌词检索。域名为 u.y.qq.com、c.y.qq.com、music.163.com、lrclib.net；接口可用性由各服务决定。
- 歌词缓存写入本插件目录的 lyrics-cache；设置使用 media-playback 自己的设置键。不会读取播放器账号、登录令牌或其他插件配置。
- 光晕在本机分析系统扬声器输出，不使用麦克风，不保存或上传音频；其他程序的声音也可能影响光晕。
- 宿主插件日志及本地 WinIsland/audio_monitor.log 用于诊断；部分取词错误日志会含歌名、歌手。安装包不包含歌词缓存、播放记录或用户配置。
